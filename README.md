# Modelling Physics Simulations with Graph Transformer Networks

This repository contains the implementation of a graph transformer network for predicting the performance of industrial vacuum systems. The model approximates simulation results to reduce computation time, potentially enabling faster and more interactive vacuum system design and optimization.

## Overview

Industrial vacuum systems are used in lifting applications and can be designed using simulation software to evaluate their performance. However, conventional simulations can be computationally expensive, making it difficult to apply traditional optimization methods in interactive design environments.

This project investigates the use of **graph transformer networks (GTNs)** to predict key performance metrics of industrial vacuum systems. By learning from previously generated simulation results, the model aims to provide fast performance estimates without requiring a full simulation for every new design.

The approach represents vacuum systems as graphs, where nodes describe system components and their associated features, and graph connectivity captures the relationships between components. A transformer architecture with masked attention is used to encode component connections and learn relationships within the system.

The model is trained and evaluated using simulation data generated by **OVM Pro 3D**, a proprietary simulation software developed by Piab AB.

### Key Results

The results demonstrate the potential of graph transformer networks to accelerate the evaluation of industrial vacuum systems:

- **Lifting performance:** Predictions were within a 10% error threshold in 81.4% of cases.
- **Energy consumption:** Predictions were within a 10% error threshold in 76.3% of cases.
- **Simulation speed:** The proposed method reduced computation time by a factor of 149 compared with the reference simulation method.

These results suggest that graph transformer networks can provide a computationally efficient approximation of industrial vacuum system simulations.

The approach could support future interactive optimization tools by enabling faster exploration of alternative system designs. The findings may also inform similar applications of graph-based machine learning to engineering simulation problems.

> **Note:** The reported accuracy percentages refer to cases within a 10% error threshold, rather than the overall prediction accuracy of a classification model.

### Method Overview

1. **System representation:** Convert industrial vacuum system designs into graphs with node features and component connectivity.
2. **Simulation data generation:** Generate reference performance metrics using OVM Pro 3D.
3. **Model training:** Train a graph transformer network using the generated simulation dataset.
4. **Performance prediction:** Predict lifting performance and energy consumption for vacuum system designs.
5. **Evaluation:** Compare the predictions with reference simulation results and measure prediction error and computation time.

## Project Setup

### Requirements

The project has been tested on **Ubuntu 24.04.4 LTS**.

- Python: 3.12.3
- pip
- Dependencies listed in `requirements.txt`

To install the required Python packages, run:

```bash
pip install -r requirements.txt
```

It is recommended to use a virtual environment to avoid conflicts with other Python projects.

For example:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Additional Files

The project requires a dataset and may also use a pre-trained model, depending on the workflow.

#### 1. Dataset

Download the dataset from the github release associated with this repository.

Place the downloaded files in the expected locations under the `data/` directory.

The dataset contains simulation results used for model training, evaluation, and testing.

#### 2. Pre-trained Model

Download the pre-trained model from the github release associated with this repository.

Place the downloaded checkpoint in the expected location under the `model/` directory.

Using a pre-trained model allows you to evaluate the model without training it from scratch.

### Generating the Dataset

Generating the dataset from scratch requires **OVM Pro 3D**, proprietary simulation software developed by Piab AB.

Because the software is proprietary and is not included in this repository, the generated dataset is provided separately.

The dataset-generation script requires a working OVM Pro 3D installation and the appropriate access to its simulation functionality.

## Running the Project

The project provides scripts for dataset generation, model training, and model evaluation.

### Run the Complete Pipeline

To execute the main pipeline, run:

```bash
python main.py
```

Check `main.py` to see the execution order and determine which steps require an existing dataset or trained model.

### Run Individual Steps

#### Step 1: Generate the Dataset

```bash
python step1_generate_dataset.py
```

Generates simulation data for model training, evaluation, and testing.

**Requirements:** A working OVM Pro 3D installation and the necessary configuration.

#### Step 2: Train the Model

```bash
python step2_train_ml_model.py
```

Trains the machine learning model to predict the target performance metrics of industrial vacuum systems.

**Requirements:** The generated dataset must be available in the expected location.

#### Step 3: Evaluate the Model

```bash
python step3_evaluate_model.py
```

Evaluates the trained model against the evaluation or test dataset. The evaluation includes metrics such as mean absolute error (MAE), mean absolute percentage error (MAPE), and computation time.

**Requirements:** An available dataset and a trained model checkpoint.

> **Note:** The scripts may depend on specific file paths, configuration settings, or model checkpoints. Consult the relevant script before running an individual step.

## Limitations and Future Work

The model approximates simulation results rather than replacing the underlying physics-based simulation software in every application. Its predictions are subject to the limitations of the training data and the designs represented in that data.

The dataset-generation workflow also depends on proprietary software, which limits the ability to reproduce the complete data-generation process without access to OVM Pro 3D.

Future work could investigate how the model can be integrated into interactive design and optimization tools, where faster performance estimates could enable the exploration of larger design spaces.
